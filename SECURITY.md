# Security policy

Security fixes target the latest maintained fork release. The initial compatibility work is still in progress; no fork release has been validated yet.

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/timlaing/ha-energy-overview-card/security/advisories/new). If that form is unavailable, contact Tim Laing at tim@laingcorp.co.uk. Include affected versions, reproduction steps and impact. Do not post credentials or sensitive Home Assistant configuration in a public issue.

Ordinary rendering, editor and compatibility bugs belong in the public issue tracker.
